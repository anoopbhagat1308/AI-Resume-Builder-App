# 📄 Resume Builder App

A simple and user-friendly **Resume Builder** built using **Python**, **Streamlit**, and **python-docx**. This application allows users to enter their personal and professional information, generate a well-formatted resume, and download it as a Microsoft Word (.docx) document.

---

## 🚀 Features

- 📋 Easy-to-use interface built with Streamlit
- 👤 Enter personal information
- 📝 Add professional summary
- 💼 Include work experience
- 🎓 Add education details
- 🛠️ List technical and soft skills
- 🚀 Add projects
- 📥 Download resume as a Word (.docx) file
- ✨ Automatic text formatting using Title Case

---

## 📦 Installation

### 1. Clone the repository

```bash
git clone https://github.com/your-username/resume-builder.git
```

### 2. Navigate to the project folder

```bash
cd resume-builder
```

### 3. Install the required libraries

```bash
pip install -r requirements.txt
```

### 4. Run the application

```bash
streamlit run app.py
```

---

## 📸 Application Workflow

1. Enter your personal details.
2. Add your professional summary.
3. Enter your skills.
4. Fill in education details.
5. Add work experience.
6. Include your projects.
7. Click **Generate Resume**.
8. Download the generated resume as a Word document.
